# Babyfolio_스토리지_최적화 <br>
```
ktcloudTechUP 1 TEAM Apple의 2차 프로젝트의 솔루션을 통해,
현재 국내 플레이스토어 1위 육아 앱인 '쑥쑥찰칵'의 성장앨범에 관하여
스토리지를 최적화하여 AWS 사용 비용은 
18억 원에서 300만 원으로 줄일 수 있으며, 
Cloudflare R2 사용 비용은 
1억 원에서 300만 원으로 줄일 수 있습니다. 
```
